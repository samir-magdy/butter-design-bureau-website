# Session Log: Sanity CMS Integration

## What was built

This session wired up Sanity as the headless CMS for the portfolio project grid. The static data array in `lib/data.ts` was replaced with a live Sanity fetch. No images are stored on the Next.js server — all media is served from `cdn.sanity.io`.

### New files created

| File | Purpose |
|------|---------|
| `sanity.config.ts` | Top-level Studio config — registers schema, Structure tool, and Vision (GROQ playground) |
| `sanity/schema/index.ts` | Schema barrel — exports the `schema` object consumed by `sanity.config.ts` |
| `sanity/schema/project.ts` | `project` document type: `title`, `slug` (auto from title), `category`, `coverImage` (image w/ hotspot), `description` (text, optional), `gallery` (array of images w/ hotspot), `order` (number, controls grid sort) |
| `lib/sanity/client.ts` | Sanity client (`createClient` from `next-sanity`) + `urlFor()` image URL builder (`@sanity/image-url`) |
| `lib/sanity/queries.ts` | GROQ queries: `projectsQuery` (grid), `allSlugsQuery` (static params), `projectBySlugQuery` (detail page) |
| `app/studio/[[...tool]]/page.tsx` | Embeds Sanity Studio at `/studio` using `NextStudio` from `next-sanity/studio` |
| `.env.local` | Env vars (filled in — Sanity project is live) |

> **Note:** `sanity/lib/client.ts`, `sanity/lib/image.ts`, and `sanity/lib/live.ts` were generated by the Sanity CLI but are **not used by the app** — app code imports from `lib/sanity/` instead.

```

  layout.tsx              — root layout (fonts, metadata, <body>)
  page.tsx                — home: HeroSection + scroll spacer + PortfolioGrid + Footer
  (site)/
    layout.tsx            — shared Navbar + Footer for inner pages
```

Home (`app/page.tsx`) is outside the `(site)` group and renders its own Navbar (inside PortfolioGrid) and Footer directly — it does not use `app/(site)/layout.tsx`.

## Architecture notes

- **Studio is embedded** at `/studio` inside this Next.js app. It's unauthenticated — access is by obscurity for a personal portfolio. Add middleware auth if the site becomes public.
- **ISR at 60 seconds** — `revalidate = 60` lives in `app/page.tsx` and `app/(site)/work/[slug]/page.tsx`. Publishing new content in Sanity appears within 60 seconds.
- **Image URLs** — `urlFor()` in `lib/sanity/client.ts` generates CDN URLs. `.auto("format")` serves WebP/AVIF. Hotspot data is stored on the image in Sanity.
- **Gallery** — project detail pages combine `coverImage` + `gallery[]` into a single slides array for the lightbox. The grid is 2-col on mobile, 3-col on sm+.
- **Contact form** — uses React 19 `useActionState` + a Server Action. No third-party form library. Validation is server-side only (client `required` attributes are a UX convenience).
- **GROQ query typing** — `defineQuery` is a pass-through tag. Fetches are explicitly typed: `client.fetch<Project[]>(...)`. Run `npx sanity@latest typegen generate` to auto-generate `sanity.types.ts` and remove manual typing.
